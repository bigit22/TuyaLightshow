# Changelog

## [0.1.0] - 2026-08-24

### Added

- Core Audio DSP engine with FFT processing.
- AGC (Automatic Gain Control) with `MIN_PEAK_FLOOR`.
- `BASS_DOMINANCE` filter to ignore vocal/chord frequencies.
- Spectral Centroid calculation for dynamic hue shifts.
- Separate network threading for Tuya API.
- CLI with background execution mode (`--background`).
- Windows VBScript integration for automated silent startup (`startup-enable`).
- `Makefile` for streamlined installation.
